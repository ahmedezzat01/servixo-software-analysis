# PDF Files Guide

The following PDF files need to be added to this directory to enable downloads:

## Required PDF Files

1. **DFD-Level-0.pdf** - Data Flow Diagram Level 0 (Context Level)
2. **DFD-Level-1.pdf** - Data Flow Diagram Level 1 (Detailed Processes)
3. **fesability.pdf** - Feasibility Study Report
4. **context-diagram.pdf** - Context Diagram
5. **use-case.pdf** - Use Case Diagram
6. **activity-diagram.pdf** - Activity Diagram
7. **casual-descriptions.pdf** - Casual Descriptions (All 3 pages)
8. **sdlc-document.pdf** - SDLC Document (if applicable)

## How to Add PDF Files

1. Convert your PNG diagrams to PDF format using a tool like:
   - Adobe Acrobat
   - Online converters (cloudconvert.com, zamzar.com, etc.)
   - LibreOffice Draw
   - ImageMagick

2. Place the PDF files in this directory with the exact names listed above

3. The website will automatically enable PDF download buttons for all diagrams

## File Naming Convention

Keep the PDF file names exactly as specified to match the download functionality in the application.
